Function Keys — Work Anywhere, Even While Typing
F1
Start a new bill (clears current)
F2
Focus item search / add products
F3
Search & select customer
F4
Apply bill-level discount
F5
Hold current bill
F6
Recall a held bill
F7
Change payment mode (Cash/UPI/Card)
F8
Save bill & print invoice
F9
Save bill without printing
F10
Open cash drawer
F12
Void bill (requires supervisor PIN)
Esc
Close modal / cancel current input
Ctrl + Key Combinations
Ctrl+S
Save & print (same as F8)
Ctrl+P
Reprint last invoice
Ctrl+Q
Focus quick-code entry field
Ctrl+F
Search item (same as F2)
Ctrl+D
Line-item discount on selected row
Ctrl+N
Quick-add new customer
Ctrl+H
Show held bills list (same as F6)
Ctrl+B
Hold current bill (same as F5)
Ctrl+G
Open today's sales summary
Ctrl+1
Open bill summary popup
Alt Keys & Row Controls
Alt+C
Quick-add new customer
Alt+1..9
Jump to item category group 1–9
+
Increase qty on selected row by 1
-
Decrease qty on selected row by 1
Del
Remove selected line from bill
Quick Code Entry (Ctrl+Q to focus)
1234 + Enter
Add item with code 1234, qty 1
1234*3 + Enter
Add item with code 1234, qty 3 (use * to separate qty)
